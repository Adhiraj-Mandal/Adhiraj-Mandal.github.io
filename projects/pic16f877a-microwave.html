01OVERVIEW

From Peripheral Drivers to a Complete Embedded System

The Microwave Oven project was developed during the Emertxe Embedded Systems Internship using the PIC16F877A microcontroller and Embedded C. The system integrates multiple hardware peripherals and firmware modules into a single real-time application.

A matrix keypad provides user input, a character LCD presents the user interface, Timer2 interrupts generate the timing base, and output logic controls the fan and buzzer. An FSM coordinates the microwave's operating modes and state transitions.

System at a Glance

KEYPAD→PIC16F877A→FSM→ CLCD / TIMER / OUTPUTS→MICROWAVE BEHAVIOR

Four Operating Modes

Macro Mode

Displays configured power and accepts cooking time before starting the countdown.

Grill Mode

Allows direct cooking-time entry and starts the cooking process after confirmation.

Convection Mode

Accepts temperature, performs preheating, then accepts cooking time and starts cooking.

Character LCD in 4-bit Mode

The CLCD provides the primary user interface, displaying the power-on message, menu, time and temperature configuration, preheating status, cooking countdown, and control instructions.

07TIMERS & INTERRUPTS

Timer2 as the Real-Time Base

Timer2 generates periodic interrupts. Software timing flags are then used by the application to create one-second countdown events and periodic UI blinking events.

Timer2 interrupt → sec_flag / blink_flag → application timing if (sec_flag) { sec_flag = 0; cook_remaining_sec--; }

Why Interrupt-Driven Timing?

The timing mechanism allows countdown processing to occur independently of the normal application flow instead of relying on blocking delays for every elapsed second.

Why FSM?

Clear State Separation

Each operating condition has a defined responsibility.

Predictable Transitions

User actions drive explicit transitions between states.

Easier Debugging

Behavior can be traced through a finite set of application states.

Extensibility

Additional modes or behaviors can be introduced as new states and transitions.

10TIME & TEMPERATURE

Four-Digit Time Entry

Cooking time is represented internally as four digits in MMSS format. For example, entering 1 → 2 → 3 → 4 produces 12:34.

Total Seconds = Minutes × 60 + Seconds

Convection Preheating

Convection mode adds a temperature configuration and preheating stage before the cooking time is entered. The fan is activated during preheating.

11OUTPUT CONTROL

Fan Control

Preheating

Fan activated while the convection system is preheating.

Cooking

Fan remains active during cooking.

Pause

Fan is deactivated while the system is paused.

Completion

Fan is deactivated after the cooking operation finishes.

Buzzer Feedback

The buzzer provides user feedback, including a completion alert when cooking finishes.

Developed the microwave oven firmware around the PIC16F877A, integrating the keypad, CLCD, timer/interrupt system, fan, buzzer, and application-level FSM. Implemented the four cooking modes, time/temperature entry, countdown, convection preheating, pause/resume/stop behavior, and quick-start operation.
