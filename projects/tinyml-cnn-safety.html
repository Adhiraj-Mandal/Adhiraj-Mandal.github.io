01OVERVIEW

From Image to Robot Control

This project was developed in two connected stages. The first stage focused on designing a lightweight TinyML CNN accelerator capable of hardware-friendly image classification. The second stage extended that accelerator into a Warehouse Vision Safety Controller (WVSC) for autonomous warehouse robots.

The resulting system demonstrates the complete path from image → AI inference → object classification → safety decision → register update → motor control.

Core Design Philosophy

The architecture separates perception from safety-critical decision making. The CNN answers “What is in front of the robot?”, while deterministic RTL safety logic answers “What should the robot do about it?”.

AI Perception

Lightweight CNN inference identifies warehouse scene classes.

Deterministic Safety

RTL logic evaluates human presence, motion, and danger-zone conditions.

Hardware Control

Register and PWM logic translate the safety decision into motor-control behavior.

Edge Operation

Hardware-oriented arithmetic reduces dependence on floating-point computation and external processing.

03PHASE 1

TinyML CNN Accelerator

A custom dataset containing 1,562 images was used to train a CNN for four warehouse-relevant classes: Human, Obstacle, Pallet, and Free Space. The trained model achieved approximately 94.9% classification accuracy and was subsequently converted to an INT8 representation for hardware-oriented inference.

Why INT8?

Quantized 8-bit arithmetic reduces memory requirements and simplifies the hardware needed for multiplication and accumulation, making the model more suitable for resource-constrained FPGA/ASIC implementations.

Lower MemorySmaller Multipliers Lower Arithmetic CostHardware-Friendly Inference

Vision Preprocessor

Incoming RGB pixels are converted to grayscale using the hardware-friendly approximation:

Gray = (R + 2G + B) / 4

The computation uses additions and bit shifting rather than floating-point operations. Line buffers retain neighboring image rows required for convolution processing.

04RTL COMPONENTS

MAC Engine

The Multiply-Accumulate unit forms the primary arithmetic element of the accelerator. Each operation follows:

Accumulator = Accumulator + (Pixel × Weight)

Activation & Pooling

ReLU

Negative activations are suppressed to zero using sign-based selection logic.

Max Pooling

A 2×2 region is reduced to its maximum value using comparison logic.

Weight Memory

Quantized INT8 weights are stored in addressable hardware-compatible memory.

Classification

The four class scores are compared and the highest-scoring class is selected.

05PHASE 2

Warehouse Vision Safety Controller

The second phase integrates the CNN accelerator into a larger RTL control system. The WVSC combines perception, deterministic safety logic, communication, register management, and motor control.

Safety Engine

The Safety Engine receives the CNN result together with motion and danger-zone information. The emergency condition is asserted when a human is detected while the robot is moving and the human is inside the defined danger zone.

06CONTROL & COMMUNICATION

Memory-Mapped Register Bank

The register bank provides a structured interface for monitoring and controlling the system. Important registers include:

0x00 STATUS 0x04 CONTROL 0x08 FRAME_START 0x0C CNN_RESULT 0x10 CONFIDENCE 0x14 SAFETY_STATUS 0x18 PWM_CONTROL

SPI Slave

The SPI interface provides an external processor with access to system registers for monitoring CNN predictions, confidence, safety status, and PWM control state. It supports register addressing, reads, and writes.

PWM Motor Controller

An 8-bit counter provides the PWM time base. The PWM output is generated by comparing the counter value with the programmed duty cycle. The safety path can force the motor-control duty cycle to zero during an emergency.

8-BIT COUNTER+DUTY CYCLE→PWM OUTPUT

09ENGINEERING DECISIONS

Hardware-Oriented Design Choices

Grayscale Conversion

Addition and bit shifting replace floating-point computation.

INT8 Arithmetic

Quantization reduces memory and arithmetic complexity.

ReLU

Sign detection and selection avoid unnecessary arithmetic hardware.

Max Pooling

Comparator-based reduction provides a simple hardware implementation.

PWM

Counter and comparator logic provide deterministic motor control.

Register Interface

Address decoding and memory-mapped registers expose system state cleanly.
