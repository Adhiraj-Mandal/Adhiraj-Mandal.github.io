01OVERVIEW

From Pixels to Object Classes

Developed an end-to-end deep learning system for image classification using a Convolutional Neural Network (CNN). The model was trained on the CIFAR-10 dataset to classify RGB images into ten predefined object categories.

The implementation covers the complete workflow from image preprocessing and CNN architecture design through model training, evaluation, persistence, and interactive inference using Streamlit.

End-to-End Pipeline

CIFAR-10→ PREPROCESS→ CNN→ TRAIN→ EVALUATE→ SAVE MODEL→ STREAMLIT→ PREDICT
02OBJECTIVE

Automated Image Recognition

The objective was to develop a computer-vision model capable of automatically identifying the class of an input image. The system accepts an image, processes it through the trained CNN, and returns the predicted object category together with a confidence score.

03DATASET

CIFAR-10

The CNN was trained using CIFAR-10, a benchmark dataset containing 60,000 labeled RGB images: 50,000 training images and 10,000 test images. Each image has a resolution of 32 × 32 pixels.

AirplaneAutomobileBird CatDeerDog FrogHorseShipTruck

04PREPROCESSING

Pixel Normalization

Before training, RGB pixel values are normalized from the original 0–255 range to a 0–1 numerical range. This provides a consistent input scale for neural-network training.

05CNN ARCHITECTURE

Convolutional Feature Extraction

The model uses convolutional layers to learn visual features from the input images. Max-pooling layers progressively reduce spatial dimensions while retaining important learned features.

Input · 32 × 32 × 3
↓
Convolution · 32 Filters
↓
Max Pooling
↓
Convolution · 64 Filters
↓
Max Pooling
↓
Flatten
↓
Dense · 64 Neurons
↓
Output · 10 Classes

Architecture Roles

Convolution

Learns spatial visual features from image pixels.

Max Pooling

Reduces spatial dimensions while retaining salient features.

Flatten

Transforms the learned feature maps into a vector for the dense layer.

Dense Layer

Combines learned features before the final ten-class prediction.

08TESTING

Evaluation on Unseen Images

After training, the CNN was evaluated using unseen images from the CIFAR-10 test dataset. The model generated a prediction corresponding to one of the ten learned object categories for each test image.

Testing Goal

Generalization

Determine whether learned visual features transfer beyond the training samples.

Classification

Verify that unseen images can be mapped to one of the ten learned categories.

Prediction Confidence

Expose the model's confidence for individual inference results.

Application Readiness

Use the trained model as the inference engine for the interactive frontend.

09DEPLOYMENT

Streamlit Inference Application

A Streamlit web application was developed to make the trained CNN usable without directly interacting with the training code. The application provides an image-upload interface and connects the uploaded image to the saved model for inference.
