AI-Driven Design Space Exploration and Optimization for Energy-Efficient Hardware Accelerators

AI-DSE++ is a constraint-aware, explainable machine-learning framework for automated design-space exploration of FPGA AI accelerators, combining architecture-preserving RTL parameterization, surrogate modeling, Bayesian optimization, and hardware-aware analysis.

01RESEARCH OVERVIEW

Why FPGA AI Accelerator DSE?

FPGA AI accelerators expose a large design space spanning compute parallelism, memory hierarchy, buffering, interconnect, precision and clocking. Each configuration can require synthesis and implementation to determine timing, resource use, power and energy, making exhaustive exploration expensive.

AI-DSE++ investigates whether machine learning can learn the relationship between architecture parameters and hardware outcomes, then guide an optimizer toward promising configurations while respecting explicit hardware constraints.

Research Objective

Can AI-driven DSE identify high-quality, energy-efficient FPGA accelerator configurations while reducing expensive hardware evaluations?
02BENCHMARK ACCELERATOR

36-PE Eyeriss-v2-Inspired Sparse CNN

The framework was applied to a 36-processing-element sparse CNN accelerator inspired by Eyeriss-v2 architectural concepts. The benchmark uses a 2×2 cluster organization, with 3×3 PE arrays inside each cluster, sparse CNN computation, im2col preprocessing, CSC-style streams, hierarchical routing, local scratchpads, GLB SRAM banks, and separate activation, weight and partial-sum routing planes.

05SURROGATE MODELING

Learning Hardware Behavior

AI-DSE++ trains tree-ensemble surrogate models to learn the mapping from architectural configuration to hardware characteristics. Two model families are compared because they handle mixed discrete/continuous, low-dimensional architecture parameters and can be retrained efficiently inside an optimization loop.

Random ForestGradient BoostingLatencyPowerEnergyLUT UsageFmaxMAERMSER²

On the controlled synthetic validation dataset, Gradient Boosting achieved reported test-set R² values between 0.985 and 0.9998 across the modeled targets.

06CONSTRAINT-AWARE BAYESIAN OPTIMIZATION

Search Feasible Configurations

Rather than evaluating arbitrary configurations, the optimizer uses surrogate predictions to restrict the candidate pool to designs expected to satisfy the hardware constraints before choosing the next evaluation.

Resource Constraints

LUT ≤ 20,000 · DSP ≤ 180 · BRAM ≤ 100

Performance Constraints

Latency ≤ 20 ms · Fmax ≥ 90 MHz

Power Constraint

Power ≤ 2.5 W

Acquisition Strategy

Balances exploitation of promising regions with exploration of uncertain regions.

07EXPLAINABILITY

Why Was a Configuration Recommended?

AI-DSE++ uses permutation feature importance to quantify how much surrogate prediction error increases when an architectural feature is independently permuted across the held-out set.

1 · Active PE Count

Strongest influence in the synthetic energy model.

2 · Clock Target

Second strongest reported influence for synthetic energy.

3–5 · FIFO / PSUM / GLB

Lower relative influence in the synthetic study.

These importance rankings describe the synthetic evaluator and are not treated as causal conclusions about real FPGA hardware. SHAP-based per-configuration explanations are identified as a future extension.

10EVIDENCE BOUNDARY & LIMITATIONS

What Has — and Has Not — Been Established

The 6.7% result is not a measured FPGA energy improvement. It is synthetic pipeline-validation evidence. At publication time, zero real Vivado syntheses had completed for the DSE configurations.

Validated

Architecture audit, PE-enable RTL parameterization, software orchestration, surrogate modeling, constrained BO and explainability pipeline.

Not Yet Validated

Real multi-configuration Vivado synthesis/implementation and hardware-derived DSE performance improvements.

Next Hardware Step

Repair the inherited Vivado source set, execute completed hardware evaluations, extract real reports, then retrain and revalidate the surrogates.
